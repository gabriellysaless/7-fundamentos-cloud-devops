# ☁️ Fundamentos de Cloud e DevOps

> **Repositório destinado aos estudos e exercícios desenvolvidos durante o módulo de Fundamentos de Cloud e DevOps da EBAC.**

Este repositório reúne os estudos e projetos desenvolvidos durante o módulo, abordando conceitos de computação em nuvem, cultura DevOps, automação de processos, performance web, Progressive Web Apps (PWAs), arquitetura de Micro Frontends e metodologias ágeis.

O objetivo é documentar minha evolução no aprendizado, compreender práticas utilizadas no desenvolvimento de aplicações modernas e ampliar meus conhecimentos sobre arquitetura, desempenho, implantação e organização de projetos de software.

## 🚀 Tecnologias e ferramentas

- JavaScript (ES6+)
- React
- Next.js
- TypeScript
- HTML5
- CSS3
- GitHub Actions
- Webpack
- Module Federation
- Chrome DevTools
- Google Lighthouse
- Web App Manifest
- Service Workers
